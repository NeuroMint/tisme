# Archive — Folder Guide

Keep it simple and chronological. This isn't a museum catalogue, just a
structure so things can be found later. Naming tip: prefix filenames with
the year, e.g. `1983 – Toronto Job Offer Letter.pdf`, so everything sorts
itself.

| Folder | What goes here |
|---|---|
| `00-project-notes` | Chapter ideas, themes, questions for family, loose memories |
| `01-autobiography-recordings` | Voice memos, named by date + topic |
| `02-autobiography-draft` | Transcripts and written chapters as they're drafted |
| `03-family-history` | Family tree, Somerset House research, family bible |
| `04-personal-life` | Childhood, school/university, marriage, children, friends, homes/travel |
| `05-career` | CV/timeline, industry articles, leadership material, pandemic leadership, career assessments |
| `06-photos` | Split by decade |
| `07-documents-and-certificates` | Passports, marriage/citizenship certificates, education certificates, awards |
| `08-media-and-memorabilia` | Music, home movies, letters, newspaper clippings |
| `09-final-book-and-archive` | Final manuscript, print files, finished digital archive |

Each subfolder has a `.gitkeep` placeholder so the empty structure is
already tracked in git — just drop real files in and the placeholder can
stay or go, it doesn't matter.

**Large media files (photos, audio, video):** if this repo grows large with
real media, consider Git LFS, or keep bulky originals in cloud storage
(iCloud/Drive/Dropbox) and only commit lower-res previews or notes here.
Not a concern yet — decide once Phase 3 is under way.
